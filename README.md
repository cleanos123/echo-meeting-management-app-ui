# Echo — Meeting & Task Management App

Echo is a UI/UX prototype designed to help teams organize meetings, tasks, departments, transcripts, and meeting summaries in one centralized platform.

## Features

- Meeting dashboard
- Task / TODO management
- Create and assign tasks
- Department and member management
- Meeting transcript viewing
- Meeting summary generation and editing
- Search and filtering
- Account and profile settings
- Interactive navigation between application screens

## Tools

- Figma
- UI/UX Design
- Wireframing
- Interactive Prototyping
- User Flow Design

## Prototype Highlights

The prototype includes several connected workflows:

- Create and manage tasks
- View meetings and meeting status
- Review generated meeting transcripts
- Edit and save meeting summaries
- Manage departments and users
- Update account settings
